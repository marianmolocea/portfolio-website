## 2. About

I've been building software for six years. I use React and JavaScript on the front end, Go on the back end, and AWS underneath.

These days I work closely with a team that builds in-house models. They build the models. I build the internal apps people use to work with them.

## 3. What I do

**Apps, start to finish**
I build whole applications from scratch. Then I connect them to the systems the company already runs on.

**Tools for in-house models**
I work side by side with the model team. When they need a new tool for their models, I build it.

**Faster, lighter apps**
I find what slows a large app down and fix it, so it runs quicker and uses less. Same app, less waiting.

## 4. Tools I use

**Frontend:** React, JavaScript, TypeScript, HTML, CSS
**Backend:** Go, Node.js, REST APIs, SQL databases
**Infrastructure:** AWS, Docker, Git, CI/CD pipelines
